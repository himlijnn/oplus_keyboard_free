# Oplus Keyboard Free

LSPosed 模块，用于修改一加设备对 Meta 键的映射。

[English](README.md) | [简体中文](README_zh_CN.md)

---

### 功能

已知一加设备的 ColorOS 将 Meta 和一些组合键设定为系统功能，将鼠标中键设为 Home，右键设为 Back。Android 原生将 Alt + Tab 设定为切换任务。模块禁用了以上键盘功能，以舒适使用 Parsec 等远程桌面软件。

暂未找到方案修改鼠标映射，您需要手动开启开发者选项中的“**禁止权限监控**”以正常使用鼠标功能。

### 兼容性

模块基于刷入 ColorOS 15 的**小米平板 5 Pro** 开发并测试。理论上支持搭载 ColorOS 的所有一加平板。不确定其它 ColorOS 设备的兼容性，请自行安装测试。

### 快速开始

- 安装 ROOT 管理器和 LSPosed
- 在 [Releases](https://github.com/himlijnn/oplus_keyboard_free/releases) 下载本模块并安装
- 重启设备后自动生效
  - 按需开启开发者选项中的“禁止权限监控”
